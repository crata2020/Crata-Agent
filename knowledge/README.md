# CRATA 지식 파일 구조

이 폴더는 CRATA AI Office가 참조할 공식 지식, 원본 자료, 에이전트 작업 가이드를 보관한다.

## 기본 원칙

CRATA 지식은 세 층으로 나눈다.

```text
_sources
= 사용자가 제공한 원본 문서에서 추출한 보존용 자료

official
= 현재 공식 기준으로 사용할 검사별 MASTER 지식

agent-guides
= 각 에이전트가 질문하고 판단하고 산출물을 만드는 작업 절차
```

## 현재 반영된 검사 지식

- 개인행동 동기검사: `official/personal-behavior-motivation/MASTER.md`
- 집단행동검사: `official/group-behavior/MASTER.md`

색채검사와 조직행동검사는 아직 원본 지식 파일이 들어오지 않았으므로, 이후 문서를 받으면 같은 구조로 추가한다.

## 공식 반영 규칙

에이전트는 원본 문서와 MASTER 지식을 참조할 수 있지만, 공식 지식을 바로 수정하지 않는다.

공식 지식 수정은 다음 흐름을 따른다.

```text
원본 입력
-> 작업 후보 생성
-> 개념수호자 검토
-> 품질검수관 검수
-> 청하님 승인
-> MASTER 반영
```

## 에이전트 사용 방식

에이전트는 답을 바로 만들기보다, 요청이 모호하면 먼저 필요한 정보를 질문한다.

예를 들어 사업설계자는 제안서를 바로 쓰기 전에 대상, 문제, 목적, 성과, 예산, 일정, 검사 활용 방식부터 확인한다. 콘텐츠전략가는 채널, 타깃, 메시지, 전환 목표, 금지 표현을 먼저 확인한다.

공통 가이드는 `agent-guides/agent-operating-guides.md`에 둔다.
